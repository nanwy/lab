# 02: 连线显示与导出一致性修复

**What to build:** 修复“S06场景拓扑还原差异修复专项”R05–R06。用户查看和编辑直线、正交折线及已有折点线路时，网卡标签沿实际路径定位；新业务连线恢复原默认蓝色虚线和流动效果，已有受支持样式实际显示。画布、保存重开与PNG/SVG视觉产物一致，既有高清PNG和标签背景修复不回退。交付包含线路数据、渲染、保存往返、导出及定向回归的完整闭环，优先级P2。可独立实施和验收；01建议先实施，但不是本票的阻塞项。

**Blocked by:** None (can start immediately).

**Status:** complete

- [x] R05：网卡标签按实际绘制路径的长度比例定位，覆盖直线、正交路由和已有非共线折点，保持原标签比例与文字，不再按源目标之间的直线插值。
- [x] 节点移动、端点旋转以及画布缩放/平移后标签仍沿线定位；保存后重新GET或重开验证线路、折点与标签一致，不以标签文字存在代替几何正确性。
- [x] R06：新业务连线恢复已确认默认蓝色、虚线参数及流动效果，样式随整图保存并重开；已有受支持动画实际生效，已有自定义颜色、粗细和虚线参数不被默认值覆盖。
- [x] 不扩展动态运行状态颜色，不新增折点编辑器或第二套线路渲染引擎；不替换图编辑库、不升级依赖，不为了本票进行无关大规模重构。
- [x] PNG/SVG解码后保留修正后的线路、图标、标签位置与背景，不出现黑块、资源缺失或尺寸回退；PNG仍直接从矢量源按三倍尺寸栅格化，SVG保持原尺寸。PNG只验收静态快照，不要求动画文件。
- [x] 锁定/共享/只读不因样式和标签修复获得编辑能力；保留已有字段、业务标识、父子关系和未知字段，直线及纯图边显示不回退。
- [x] 用现有隔离浏览器场景先复现红灯，以偏移端点、非共线折点及正交路径验证实际线路和标签DOM几何；核对默认/自定义样式、保存重开，以及实际下载文件的尺寸和像素。截图仅作补充，不以私有state或同算法重算自证正确。
- [x] 仅运行新增及直接影响的浏览器用例、最小web类型检查、改动文件lint/格式；其余未变结果复用。更新实际交付和验证记录，区分静态证据、隔离验证与真实联调，不运行全量检查或未经授权的真实业务写入。
