# 01: 实验拓扑读取、编辑与保存闭环

**What to build:** 学员从实验进入场景拓扑，查看真实接口返回的节点、端口、边和分组，移动节点后保存并重新打开，确认设计被持久化。读取、编辑和保存始终归属当前实验。本票属于 S06、F036，对应 US17、US23–US25；前置 S05 已完成。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 实验场景拓扑入口使用实验上下文中的拓扑标识；按既有调用链补齐契约，明确实验 ID、拓扑 ID 和节点业务 ID 的区别，不猜测备用字段。
- [ ] 使用 React Flow 展示原入口支持的设备、端口、边和分组，支持缩放平移、合法空图、加载失败重试及资源不存在的恢复入口。
- [ ] 原始 X6 图与编辑器模型双向适配，保留业务标识、父子关系、坐标、端口、角度、折点、路由、连接器、样式及未知字段。无法支持的图元或无效关系明确报告并保留原始数据，不能静默丢弃。
- [ ] 可编辑状态下移动节点，经统一请求客户端写入后端；重新请求或重新进入页面后，节点位置和其他原有语义一致，不能以内存序列化往返代替持久化验收。
- [ ] 保存失败保留草稿和未保存状态，成功后才更新保存基线；保存期间产生的新编辑不被旧响应覆盖。离页、切换实验及刷新按需要提示未保存修改。
- [ ] 根据原入口的只读、共享、锁定及编辑能力分支控制操作，查看仍可用，禁止的修改不能通过画布事件或其他入口提交。
- [ ] 切换实验或离页取消读取并隔离迟到结果；接口错误复用统一 toast 和权限跳转，组件仅处理自身恢复，不重复提示。
- [ ] API 适配与数据往返契约测试、浏览器读取—移动—保存—重新读取流程通过；覆盖失败保留草稿、未保存提示、只读和实验切换。仅运行受影响检查，区分自动化隔离验证与真实后端联调结果。
