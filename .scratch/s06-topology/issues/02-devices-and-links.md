# 02: 设备节点与链路管理

**What to build:** 学员从设备面板将允许使用的设备拖入实验，配置或删除节点，通过合法端口创建、配置和删除链路，并编辑支持的折点。重新打开后设备配置和网络结构保持一致。本票属于 S06、F036，对应 US16、US18、US19 及相关 US22–US25。

**Blocked by:** 01: 实验拓扑读取、编辑与保存闭环。

**Status:** ready-for-agent

- [ ] 设备面板读取当前实验入口可用的资源，恢复原有浏览、筛选和选择行为及加载、空数据、失败重试状态；资源限制以已确认契约为准。
- [ ] 拖入设备时正确转换画布坐标并创建业务节点，区分图元 ID、设备标识和服务端节点 ID；创建失败不留下可被误认为已持久化的节点。
- [ ] 可查看和修改原入口支持的节点属性，覆盖实际存在的设备类型配置分支。配置表单使用项目统一写法，不添加无证据的校验或字段协议，失败保留输入。
- [ ] 端口连线按原调用链处理合法端点、环路和多重连线规则，保留两端节点及端口归属；业务关系与画布连线保持一致。
- [ ] 可编辑链路配置及支持的折点；保存重开后端点、端口、折点、路由、连接器和样式一致。
- [ ] 删除节点或链路按原协议处理关联关系，失败不伪报成功或破坏现有设计；成功后重新读取结果一致。
- [ ] 为节点和链路提供原功能支持的选中操作、工具栏和右键菜单；所有写入口遵守当前实验权限，复用保存失败恢复及离页保护。
- [ ] 定向契约测试和浏览器流程覆盖新增—配置—连线—修改—删除—重新打开，以及请求失败、只读和非法连接；不自动执行未获授权的真实业务写入。
