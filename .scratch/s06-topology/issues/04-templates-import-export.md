# 04: 模板与导入导出

**What to build:** 学员复用实验入口实际支持的拓扑模板和分块模板，通过导入导出保存、传递和恢复设计。应用或导入后节点、链路、配置及分组完整，并可保存重新打开。本票属于 S06、F042 的模板/导入导出部分及 F036 的相关能力；流量模拟和镜像仍归 S08。

**Blocked by:** 03: 分组、图元与高级画布交互。

**Status:** ready-for-agent

- [ ] 按当前实验入口和 task_type 的原始调用链确认拓扑模板、分块模板及文件导入导出的适用能力、格式和请求顺序；记录不适用能力及依据，不将其他入口的按钮直接搬入。
- [ ] 实现有证据支持的模板浏览、详情、保存、应用及管理操作，覆盖加载、空数据、请求失败重试和权限限制。
- [ ] 应用模板按原协议处理节点图元 ID、业务 ID、端口、边、分组及配置引用，不因 ID 冲突串改已有对象，不将模板状态与流量状态混存。
- [ ] 导出生成原协议要求的可用产物，保留设备配置、连线关系、位置、分组、图元和未知字段；需要服务端生成或校验的产物使用相应真实接口。
- [ ] 导入合法文件后能恢复并保存设计，重新读取结果一致；格式或接口失败明确报错并保留原设计与可恢复的操作状态，不伪报成功。
- [ ] 模板应用和导入涉及覆盖或替换时，按已确认业务行为保护未保存修改；写操作遵守权限和未知副作用操作不自动重试的规则。
- [ ] 定向测试覆盖模板保存—应用—重开、导出—导入—保存—重开、引用冲突及失败恢复；检查导出实际内容，真实后端写入仅在明确授权范围执行。
