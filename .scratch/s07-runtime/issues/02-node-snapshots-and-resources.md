# 02: 节点快照、镜像与运行资源管理

**What to build:** 学员查看当前节点详情，管理允许的快照和镜像，执行节点转换、网络入口设置、NAT 管理及适用的节点文件上传，并按原调用链更新界面。覆盖 S07 / F037 的运行资源，设计属性与设备库沿用 S06。

**Blocked by:** 01：实验场景与节点生命周期。

**Status:** ready-for-agent

- [ ] 沿已确认菜单逐项核对设备类型、运行状态、共享/锁定条件、弹窗及请求；可达入口形成闭合清单，不能仅按 API 名称扩展功能。
- [ ] 快照列表、分页、恢复与删除按原规则工作，落实启用状态及覆盖当前环境的提示；仅在确认可达创建入口时提供创建。
- [ ] 保存镜像落实设备能力、关机及关联镜像约束，保留原处理中与错误反馈，按原调用链刷新。
- [ ] 节点转换、设置入口和 NAT 网络按各自上下文查看与修改，按原调用链更新；不混用节点 UUID、业务行 ID 和运行标识。
- [ ] 节点上传仅在原菜单支持的设备与控制台条件下开放，参数、成功判据与存放提示按证据还原。
- [ ] 沿用既有表单、统一 API 错误和请求取消；失败不伪报成功，不另建草稿持久化或恢复机制。
- [ ] 捕获、嗅探、流量拦截/模拟/镜像留在 S08；不存在入口的扩展操作不新增业务按钮。
- [ ] 隔离验收快照恢复/删除、关机保存镜像、节点转换、入口/NAT 与上传的完整流程，覆盖禁止、拒绝、失败恢复和重读结果。
- [ ] 复用现有组件、请求与提示，仅补原入口需要的逻辑；使用既有测试设施验收关键操作和清理，运行受影响检查，不新增通用框架或重复测试体系。
- [ ] 区分隔离验证与真实后端联调；真实连接及资源写入仅在明确授权的测试账号、对象与动作范围内执行，不以模拟结果冒充远端执行。
