# 03: 文本终端连接、交互与恢复

**What to build:** 学员从运行节点或独立深链进入文本终端，完成远程输入输出，按原提示手动重连，并在关闭时释放前端连接资源。覆盖 S07 / F037、F046 的字符终端入口。

**Blocked by:** 01：实验场景与节点生命周期。

**Status:** 完成

- [x] docker/vpcs 以及原调用方类型映射使用已确认的节点连接标识，支持独立深链及操作机的文本连接入口，非法类型或缺失上下文明示失败。
- [x] 使用真实终端客户端与已确认 WS 路径完成双向输入输出，恢复心跳及闲置断开提示，断线不显示本地回显冒充远端连通。
- [x] 沿原连接回调和闲置断开提示处理反馈与手动重连，不另建连接状态面板或自动重连策略；关闭或重连前释放本次创建的连接、终端、监听和计时器。
- [x] 切换节点、路由或卸载后不继续发心跳、输入或重连，不把旧会话输出写进新终端。
- [x] 隔离验收双向 WS 数据、深链刷新、拒绝/超时、闲置断开、重连、关闭和非法参数；操作机入口复用同一终端页面，不预建通用终端框架。
- [x] 复用现有组件、请求与提示，仅补原入口需要的逻辑；使用既有测试设施验收关键操作和清理，运行受影响检查，不新增通用框架或重复测试体系。
- [x] 区分隔离验证与真实后端联调；真实连接及资源写入仅在明确授权的测试账号、对象与动作范围内执行，不以模拟结果冒充远端执行。
