# 04: 图形控制台、远程桌面工具与操作机面板

**What to build:** 学员从设备或操作机入口连接 VNC/RDP，在独立、嵌入和全屏界面使用键鼠、组合键、剪贴板和会话文件传输，并完成操作机选择、启动、释放与连接恢复。覆盖 S07 / F037、F046 的图形与操作机闭环。

**Blocked by:** 01：实验场景与节点生命周期。

**Status:** 完成

- [x] 独立、嵌入及全屏复用 Guacamole 连接核心，按证据区分 VNC、RDP、外部协议与后端返回的 noVNC URL；完成 RDP 准备请求及条件门控。
- [x] 初始化、等待、连接、断开与原错误分类可见；原错误分类通过现有提示呈现，重连沿原确认操作，不扩展自动恢复流程。
- [x] 键鼠、组合键与尺寸同步正常；重连前释放旧连接，路由/会话切换清理键鼠监听、流和延迟任务。
- [x] 按 RDP 连接状态开放文本剪贴板和文件管理，处理焦点、剪贴板权限拒绝、空目录、路径导航与返回。
- [x] 通过当前远端会话执行目录浏览、获取和上传，沿原协议回调报告结果，验证关键传输内容与失败反馈；不新增校验和、断点续传或传输队列，不依赖 S09 网盘。
- [x] 独立与嵌入/全屏共用桌面工具，切换会话不串用文件系统、剪贴板或输入；操作机列表、无分配、选择、启动、释放与刷新均可工作。
