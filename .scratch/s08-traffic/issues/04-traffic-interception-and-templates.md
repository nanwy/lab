# 04: 节点流量拦截、实时日志与模板复用

**What to build:** 还原拦截节点的策略、脚本、规则生成、草稿保存、启停与日志，以及拦截模板的管理、应用和导入导出。属于 S08、F042，关联 US029。

**Blocked by:** None (can start immediately). 前置 S07 已完成。

**Status:** ready-for-agent

- [ ] 按原节点类型、运行状态与菜单门控显示拦截动作，使用原拓扑标识和节点 UUID。
- [ ] 还原协议/IP/端口、Python 脚本、规则生成与草稿保存，保留原校验、未保存时禁止启动及运行中禁止编辑；不额外增加 IP/端口必填限制。

- [ ] 定向验证保存—启动—日志—关闭及模板另存/应用/导入导出，覆盖必要的失败、运行锁定和清理；检查受影响代码的类型、lint 和格式。
