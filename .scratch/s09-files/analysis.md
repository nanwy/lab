## 范围与现状

S09 前置为已完成的 S02，覆盖 F033、F047，主要对应 US087–089。交付入口为资源网盘、独立文件阅读页和 Office 跳转页。US042 的课程附件由后续课程消费者接入，不能把 F033 清单中的平台、课程附件候选接口都接入个人网盘。

拆票时资源网盘已有导航，但仍落入后续页面占位；两个独立预览路由尚未接入。已有统一请求客户端支持 FormData、超时、取消及 Blob；平台配置已解析 onlyoffice_url，流量嗅探指南已直接打开 Office 服务。桌面远端文件系统属于 S07，不是本网盘的数据源。

沿用现有请求、账号 Query、表格、表单、弹窗和错误提示。文件域基础随第一条可用流程交付，不单设横向框架或预重构票。上传进度需要在统一请求边界解决；不因当前 fetch 客户端没有上传进度而伪造百分比或另建无认证的请求旁路。

## 视觉验收与自审约定

来源：用户于 2026-10-24 对本次 S09 的明确补充。S09 的视觉设计在本次实施中同步完成，覆盖本票控制的页面、弹窗、播放器、进度与反馈状态，优先于既有“样式翻新后置”的阶段安排。业务行为、权限与数据契约继续按原证据及项目规则实施。外部 Office 服务自身的界面不属于本地可修改范围，本地跳转页及反馈仍须验收。

目标：build page to award-tier visual standard。对照 Awwwards、Webby Awards、FWA 获奖作品，在以下全部 CHECK 维度完成设计与评审。用户给出的最终目标为“no visible improvement remaining across all CHECK dimensions”；实际交付需用检查结果和页面证据说明判断，不以功能测试通过或主观宣称获奖代替视觉评审。

| CHECK             | 本次验收关注点                                                                                                                       |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| typography        | 中文与数字排版、字号与字重层次、长文件名和长路径的可读性、正文阅读宽度。                                                             |
| whitespace        | 页级节奏、工具栏与表格密度、留白与对齐；不同宽度下不拥挤、不出现无意义空洞。                                                         |
| visual_hierarchy  | 公开/个人范围、当前位置、主操作、选择状态、危险操作与任务反馈层级清晰。                                                              |
| color             | 有辨识度且一致的色彩体系、状态语义和足够对比度，状态不只靠颜色传递。                                                                 |
| motion            | 转场、展开与进度反馈服务于操作理解，保持流畅并支持减少动态效果偏好。                                                                 |
| micro_interaction | 悬停、键盘焦点、按下、选中、禁用、等待、取消、成功与失败反馈精确一致，不伪造完成。                                                   |
| responsive        | 在窄屏、中等宽度与桌面检查列表、路径、工具栏、弹窗和阅读布局，关键动作始终可达；允许表格在明确容器内滚动，不出现页面意外溢出或遮挡。 |
| originality       | 围绕资料管理与阅读形成具体设计表达，与现有应用相协调；避免直接套用通用仪表盘模板或堆叠装饰。                                         |

完成后执行自审循环：读取当前实际页面 → 按八维逐项对照获奖作品 → 记录差距 → 修正 → 重新读取受影响页面并复查八维。循环至没有已识别但未修复的可见差距；存在阻塞或无法检查的维度时如实保留，不标为视觉验收完成。

实施时记录实际参考作品的名称、链接和借鉴维度，依据具体作品进行比较；本轮只是落票，尚未选取或评审参考作品。保存受影响视口和正常/空/加载/错误等实际适用状态的截图、操作观察，以及差距修正和复查结论。01 建立本切片的视觉表达，02、03 沿用；04、05 在各自独立页面保持一致，不因视觉复用增加虚假的功能阻塞边。自审与 UI 验证限定 S09 及其直接受影响消费者，不扩成全站改版。
