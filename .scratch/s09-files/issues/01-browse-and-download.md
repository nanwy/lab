# 01: 公开与个人资料浏览、下载及公开打包

**What to build:** 从资源网盘进入公开/个人两个数据域，浏览目录并获取资料，形成最小完整文件流程，同时建立实际消费者需要的路径和类型边界。

**Blocked by:** None (已满足)。真实取样已确认本域打包响应；目录基础已集成。

**Status:** complete

- [x] 两个页签正确请求各自列表，支持根目录、上级、深层面包屑、排序、空目录与错误恢复；路径含中文和特殊字符时保持业务路径不变且按原契约编码。
- [x] 还原非 Office 名称链接、文本下载、MP4 弹窗与单文件下载；Office 名称维持原行为。公开多选文件/目录按资源 ID 打包，返回上级行不得选中或提交。
- [x] 分别还原个人与公开资料的下载命名规则，验证各自去除服务端文件标识后的名称；不统一替换为 URL 尾段或显示名。多点文件名等原算法缺陷如需修正，记录原行为、新行为、理由与验证结果。
- [x] 公开打包先确认返回文件地址的响应契约；存在多个已确认协议版本时显式分支适配，不猜字段或逐 key 兜底。未取得可获取产物时不报告下载成功；契约无法确认时记录公开导出子流程阻塞，浏览与直接下载可继续实施，但本票不得整体关闭。
- [x] 公开域没有写操作；个人表格保留来源、共享状态及共享文件标识，为后续操作提供准确对象。
- [x] 切换页签、目录或账号后，旧选择、正文/播放器及迟到响应不污染当前域；失败不显示旧目录为新目录。
- [x] 隔离验证两个列表契约、路径及获取/公开导出主流程；实际下载内容、真实签名权限与打包服务另行记录验证边界。
- [x] 本票新增或修改的界面满足[视觉验收与自审约定](../analysis.md#视觉验收与自审约定)的全部八项要求；按 Awwwards、Webby Awards、FWA 获奖作品对照，修正发现的差距后重新检查，直至无已识别且未解决的可见改进项，并保存证据。

实施进展：真实取样已确认 download_url 响应，打包接入及失败/切域回归通过，本票按实际范围关闭。证据与个人产物实体未验证等边界见[S09实施记录](../../../docs/planning/s09-implementation.md)。
