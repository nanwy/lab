# 03: 个人资料多文件上传、真实进度与取消

**What to build:** 向当前个人目录上传多个文件，显示真实字节进度，允许取消，收到成功响应后刷新对应目录。

**Blocked by:** 01：公开与个人资料浏览、下载及公开打包。不依赖 02。

**Status:** ready-for-agent

- [ ] 请求包含正确 parent_path、多个 attached、既有认证/CSRF和原超时；需要进度传输适配时保持统一请求及错误处理语义。
- [ ] 显示已上传/总字节，响应前不提前宣告成功；取消、超时和失败可再次选择上传。
- [ ] 切换账号或离页清理本票请求；切换目录后旧上传完成不得污染新目录，刷新范围以提交时上下文为准。
- [ ] 验证多文件成功、取消/失败恢复和目录切换；不新增断点续传、上传队列、自动重试、配额或格式限制。
- [ ] 本票新增或修改的界面满足[视觉验收与自审约定](../analysis.md#视觉验收与自审约定)的全部八项要求；按 Awwwards、Webby Awards、FWA 获奖作品对照，修正发现的差距后重新检查，直至无已识别且未解决的可见改进项，并保存证据。
