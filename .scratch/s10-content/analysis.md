## 工程选择与验收

- 各域独立适配和 Query key；账号、实验、目录、笔记、共享范围改变时，正文、选择、草稿与上传的迟到结果不串域。
- 原 HTML 的文字格式、图片地址/尺寸及只读显示需往返验证；输入净化与图片来源限制保持安全且不静默破坏合法内容。原 host 字符串判断、保存后 noteId 不刷新等问题按明确差异修正记录。
- 请求经统一客户端处理认证、CSRF、业务失败与取消；图片请求保留原 ul/Ae 认证策略差异。错误只提示一次，不为不可知规则增加本地校验。
- 每票验收适用的正常、加载、空、失败、禁止访问、离页与切对象；保存失败保留草稿，取消不会写入后端。
- Word 必须核对下载地址与内容，不以点击按钮或状态为成功替代产物。隔离测试证明前端流程；真实 Word 正文/图片未验证时明确保留产物验收缺口，不写成真实联调通过。
- 沿用当前 UI 组件与视觉体系。本轮未新增 S09 专属获奖级视觉要求；不把原项目局部任务约定自动扩展成 S10 的新范围。
- 验证仅限每票及直接影响的契约测试、浏览器流程、web 类型和显式文件 lint/格式检查；文档阶段仅检查格式、链接及数据一致性，不启动应用、不跑业务测试或构建。
