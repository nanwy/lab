# 01：场景笔记读取、富文本图片、保存重开与 Word 导出

**Type:** AFK

**Status:** complete

**User stories:** US032、US033；F039。

## What to build

实验的场景笔记页提供完整编辑与文档导出流程。共享内容能力在这个实际消费者中建立，供个人笔记及实验说明复用；实验 ID、笔记 ID 与图片上传上下文不得混用。原工具栏、图片操作及静态协议见[契约](../editor-contracts.md)。

## Acceptance criteria

- [x] 深链及实验内导航能读取当前实验笔记；原 GET 的 id/content 和合法空笔记协议明确，缺字段或类型错误不能伪装空笔记。只按已确认的原调用链接入，不把 admin 路径改为 front。
- [x] HTML 读取、编辑、保存、重新读取保持合法内容及可见格式；覆盖标题、行内格式、引用/代码、三类列表、缩进、上下标、方向、颜色/背景、对齐、清格式、图片尺寸/预览及编辑全屏。选择兼容当前 React 的实现，不引入缺失的业务能力。
- [x] 图片选择、拖入、粘贴 base64 经原上传流程返回 URL 后插入；FormData 为 image、mode=scene，本消费者不传 uuid；CSRF 与原不经 Ae Token 拦截器的策略在统一客户端内明确表达。仅从响应体 data.url 读取成功地址，不猜 key。
- [x] 上传失败可恢复，卸载和对象切换取消或隔离旧上传结果；旧请求不能插入新实验正文。图片来源检查不被 HTML 中的 host 文本绕过；净化与原逻辑差异有依据和验证。
- [x] 保存仅发 content；成功后确认持久化并获得当前有效 noteId，再允许导出。首次新建、重复保存、失败重提、后台刷新和实验切换均不会丢草稿或串写；适用的未保存导航按应用约定处理。
- [x] Word 请求携带当前实验与已保存 noteId，从响应体 data.file_path 获取产物，沿原 jf 命名规则下载；失败或缺地址不得提示成功。明确未保存内容的导出语义，不擅自增加自动保存。
- [x] 关键契约和隔离浏览器流程覆盖空/加载/拒绝/失败、首次保存后导出、图片插入与内容重开、迟到响应及清理。真实 Word 正文和图片核验单独记录，未完成时保留验收缺口；不以 HTTP stub 证明真实产物可用。
- [x] 验证范围遵守[共同验收](../analysis.md#工程选择与验收)；保存共享内容基础的实际交付证据，使 02/03 可在 Word 真实产物尚未核验时复用已完成能力。

S05 及 S09 已交付客户端基础已满足；不依赖 S09-05。无实施前置阻塞。合法空笔记响应及真实产物如缺少足够契约证据，明确阻塞对应流程，不把坏响应吞为空值。用户已确认拆分，可按声明的前置领取。

实施及验收：本票已合入 `integration/s10-content`，范围、定向检查、审查修正和真实联调边界统一见[实施记录](../../../docs/planning/s10-implementation.md)。真实 Word/权限等未实测不冒充通过。

空正文协议已由用户授权的真实只读取样确认：有效数字 id 与 content 空字符串，实际编辑器可打开。无需新增无 id 创建协议；缺字段响应继续明确报错。
