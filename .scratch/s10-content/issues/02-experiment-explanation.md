# 02：实验说明编辑、取消与保存刷新

**Type:** AFK

**Status:** complete

**User stories:** US031；S05 已明确交接的说明编辑。

## What to build

将当前只读实验说明接入同一内容能力。阅读已保存 overview，编辑从其初始化，取消恢复阅读，确定后保存并刷新实验详情。说明是实验元数据，不是场景笔记，不增加 Word 导出入口。

## Acceptance criteria

- [x] 已存说明及合法空说明可阅读，显示格式与图片保持兼容；切换实验不展示旧说明为新说明。
- [x] 编辑/取消/确定行为与 Ujs 一致。取消丢弃当前说明草稿且不发送保存；失败保留草稿，成功退出并重取实验详情。
- [x] 保存 PATCH 原 experiment/{id}/?more=1，body 仅 overview；明确适配响应，不借名称/标签编辑表单补入无关字段，不覆盖并行编辑的基本信息。
- [x] 图片上传复用已完成内容基础，mode=scene、不传 uuid；来源校验、失败恢复、只读图片预览、编辑全屏及历史 HTML 往返按[原契约](../editor-contracts.md)验收。
- [x] 原 Ujs 没有的角色/运行状态规则不自行添加；后端拒绝沿统一错误处理，提示一次。对象切换、取消后重开、后台刷新及迟到上传不污染当前正文。
- [x] 隔离浏览器覆盖阅读→编辑→取消、编辑→上传→保存→重开、失败后重提及切实验清理；只回归实验说明与受影响的基本信息消费者，按[共同验收](../analysis.md#工程选择与验收)记录真实验证边界。
