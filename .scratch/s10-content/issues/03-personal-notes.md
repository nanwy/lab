# 03：我的笔记目录、笔记管理、正文保存及 Word 导出

**Type:** AFK

**Status:** complete

**User stories:** US084、US085；F032。US042 仅保留原课程跳转上下文，课程消费者归后续课程切片。

## What to build

我的笔记页提供默认训练归档和自定义文件夹，选目录后搜索、选择与编辑已有笔记；自定义目录还能新建笔记。支持目录/笔记整理及个人 Word 导出。目录、元信息与正文的请求归属分别适配，不能套用网盘目录或分享协议。详细调用链见[静态契约](../personal-contracts.md)。

## Acceptance criteria

- [x] 目录直接数组，按原 nopage/search 请求和最长 300 字搜索；type1–4 默认归档父项仅展开，选择课程子项；type>4 自定义文件夹可直接选父项。默认选中、无目录、无子项及未选择状态明确，不发送 undefined ID。
- [x] 新建目录、仅自定义目录改名/删除；名称仅原必填与 50 字限制，不新增 trim/白名单/重名/配额规则。删除明确确认“文件夹及其下笔记”，成功后刷新，删除当前目录清理选中。服务端级联结果单独记录，不能用列表消失替代真实删除验证。
- [x] 个人列表保持原直接数组、200ms 搜索、section_id/course_id/type 的分支参数；无原分页、多选或排序的地方不新增。切换目录后自动选首个合法笔记，空列表清理详情。
- [x] 聚合页面默认归档无新建按钮，自定义目录才可新建；已有笔记改名与删除沿原门控，逐项删除确认，拒绝/业务失败不刷新为成功。元信息在目录 notes URL 新增/修改，正文固定 PATCH user/note/{id}/，两者不可互换。
- [x] 正文详情、富文本保存重开、图片上传 mode=notes（不传 uuid）、图片预览与导出构成完整闭环。格式兼容复用 01；原正文保存没有 rpt 检查，不因复用场景笔记而额外添加该业务限制；输入安全净化和粘贴来源策略仍在共享编辑器边界执行。
- [x] Word POST user/note/{id}/export/ 无 body；响应体唯一 data.file_path，保留原 URL 后附时间戳的导航行为或记录有依据的修正；导出已保存版本，不偷偷保存未提交草稿。缺地址、失败及无有效 ID 不报告成功，真实正文/图片核验另记。
- [x] 既有视频驻点保留可见时间和 can_enter 读取后导航，携带 section_id、breakpoint_time；can_enter URL 为 open_courses/{courseId}/can_enter/，不把课程正式运行作为 S10 完成条件。聚合页不新增驻点创建。
- [x] 请求/选中/草稿以账号、目录、笔记隔离，删除、切目录、取消和后台刷新后不串写；失败保留当前草稿，迟到读取/上传不覆盖新正文。
- [x] 契约及隔离浏览器覆盖默认/自定义门控、目录删除确认、笔记新增改名删除、保存重开、导出、驻点跳转和异常清理，按[共同验收](../analysis.md#工程选择与验收)完成定向检查。分享与评分在 04 交付，不以本票完成宣称全部 F032 完成。
