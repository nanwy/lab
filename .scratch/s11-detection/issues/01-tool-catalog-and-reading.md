# S11-01：五类检测工具目录与阅读

**Type:** AFK

**Status:** complete（静态契约与隔离验收；真实服务仍未验证）

**User stories:** US034；F040 的目录、基本信息及手册子能力。

## What to build

从实验“检测手段”入口进入五类工具目录，默认选择列表首项并阅读工具基本信息、附件/镜像信息与只读使用手册，支持切类和切工具。交付完整路由、请求适配、界面及隔离验收闭环。范围与证据见[共同分析](../analysis.md)，资料行为由02交付。

## Acceptance criteria

- [x] 五类导航及各自深链可达，映射 tool_type=1–5；浏览器前进/后退与当前分类一致。原 detection 容器默认高亮不冒充路由跳转，不自行增加 other 导航或搜索/分页功能。
- [x] 原 GET tools/ 仅按 tool_type 获取列表，消费 results；卡片显示名称和标签，非空列表自动选首项，点击切换读取 tools/{id}/。不调用未使用的固定空 getToolList，不将实验 id 混入工具过滤。
- [x] 基本信息正确显示名称、描述、载体、账号与标签。tool_carrier=1 时以 carrier_path 展示附件链接；其他分支显示 image_info.name 镜像说明，不新增启动环境动作。可选/空字段语义经证据确认，必填缺失明确报错。
- [x] 使用手册按唯一 user_manual 来源复用现有只读内容能力，格式、图片及已有预览行为兼容；没有编辑/保存入口。原详情三页签结构有稳定接入点，资料子能力未交付时明确标明，不伪装成已查询的空资料。
- [x] 列表/详情加载、空、请求失败、契约错误及访问拒绝可区分；失败可重读，已处理错误不重复提示。切类、切工具、切实验和账号变化后旧选择与迟到响应不污染当前页面，不发明角色或实验运行门控。
- [x] HTTP契约与隔离浏览器覆盖五类参数、首项/切项、附件/镜像分支、手册只读、空列表、列表/详情失败恢复及交错响应。按共同验收限定检查范围，记录静态证据、模拟验证和未验证的真实行为。
