# S11-02：工具相关资料与下载导出

**Type:** AFK

**Status:** ready-for-agent

**User stories:** US034；F040 的相关资料子能力。

## What to build

在选中工具的“相关资料”页签中浏览目录、选择文件、下载、播放视频并批量导出ZIP。沿该工具独立资料接口贯通请求、界面、产物地址与隔离验收。范围及原始证据见[共同分析](../analysis.md)。

## Acceptance criteria

- [ ] GET tools/{id}/materials/ 发送工具 id 与 parent_path，读取独立资料契约；不直接套用网盘响应、接口或对象归属。切换工具回到根目录，清空旧选择和资料，迟到响应不串工具。
- [ ] 无分页表格显示名称、大小和修改时间；名称/大小/时间排序保留原语义，create_time显示与altertime排序不混淆。支持双击目录、上级、根目录及面包屑，长路径按原末三级规则展示；上级行禁止选择/下载，目录下载按钮禁用。
- [ ] 文件名链接、单文件下载及命名沿原 attached 来源和原下载命名规则；视频名称打开播放器，关闭/离页释放本地资源。Office名称保持普通文本，不新增编辑器/预览器；文件类型图标和链接/文件夹/普通文件大小展示分别处理。
- [ ] 选择状态及已选数量正确，空选择禁用批量导出，提交前排除上级等无效项；切目录或重新取得列表清选择，资料页签卸载清选择。POST tools/{id}/materials/export_zip/ 的 body 仅 material_ids，执行中禁重复提交。
- [ ] 依据[资料契约补证](../material-contracts.md)，在适配边界只支持原消费者明确首选读取的 download_url 静态协议；不得实现 download_url/url/字符串逐个猜测。缺地址、类型错误或业务失败不显示下载成功。隔离下载核对ZIP文件字节和内容；真实唯一响应形态及真实ZIP产物保持未验证，不以fixture或点击锚点冒充真实验收。
- [ ] 正常、空目录、加载、读取/导出失败、契约错误、访问拒绝及恢复可验证；错误提示一次，失败不切换数据源或伪报成功。工具/实验/账号变化、切页及关闭视频不残留旧资源和选择。
- [ ] HTTP与隔离浏览器覆盖目录进退/面包屑、排序、选择/重置、单下载、视频/Office区别、ZIP参数与失败恢复、切工具交错响应；只回归直接影响的目录/阅读消费者。记录真实响应及产物的未验证边界，不执行未获授权的真实导出。

## Blocked by

[S11-01](01-tool-catalog-and-reading.md)已实际交付并验证的工具选择、详情上下文和资料页签接入点。本票按原消费者首选字段的静态分支实施并隔离验收；若该静态分支仍有无法补证的契约缺口，明确阻塞相应流程，不宣称完成。真实协议与产物验证独立记录。
