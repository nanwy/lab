# S11 手动测试页面与路径

## 隔离测试页面

[打开本地测试实验](http://127.0.0.1:4196/#/basic/user/bench/experiment/one/detection/penetration)。页面标题为“S11 本地测试实验（隔离数据）”，所有API与媒体由本机4296测试服务返回，不访问原后端；虚构账号信息仅用于展示。

若服务已经退出，在仓库根目录运行：

```bash
fnm exec --using 24.14.0 node scripts/s11-preview.mjs
```

默认使用4196页面端口、4296测试API端口，独立于原5173开发服务。端口占用时同时设置 `S11_PREVIEW_PORT` 与 `S11_PREVIEW_API_PORT` 为一组空闲端口，并按新页面端口访问。停止服务使用 Ctrl+C。

## 测试路径

1. 切换“渗透测试 → 防御验证 → 基线检查 → 漏洞扫描 → 风险评估”；每类均有工具A/B，分类名称与URL同步，浏览器后退/前进恢复对应分类。
2. 默认选择工具A，基本信息显示附件；切换工具B显示“本地测试镜像”，没有启动环境按钮。
3. 打开“使用手册”，查看标题与加粗格式；正文只读，没有保存入口。
4. 打开“相关资料”，双击 samples 文件夹进入，点击上级或“全部文件”返回；点击名称、大小、修改时间表头核对排序。
5. 点击 README.txt 行的“下载”，取得本地文本样例；manual.docx 名称为普通文本，仍可用该行下载按钮，不额外进入Office预览器。
6. 点击 sample.mp4 文件名，打开视频播放器；可播放约1秒的本地蓝色视频，关闭后返回资料表格。
7. 勾选 README.txt，点击“批量导出”；ZIP可解压并包含 README.txt（内容为 `S11 local fixture`）。该归档只验证本地传输和前端下载链路，不代表真实工具资料打包。
8. 切换目录、工具或分类，确认旧选择清空，新工具资料从根目录读取。上级行不能勾选、目录行不能单独下载。

加载、空数据、HTTP/业务/契约错误、访问拒绝、重试及迟到响应由定向自动化覆盖；手动服务只提供确定的成功样例。

## 真实开发入口

[原开发服务的实验列表](http://127.0.0.1:5173/#/basic/user/bench) → 选择有权访问的实验 → 检测手段 → 任一检测分类 → 工具 → 基本信息/使用手册/相关资料。

真实深链格式：`/#/basic/user/bench/experiment/{实验id}/detection/{分类}`，分类为 penetration、defense、baseline、vulnerability 或 riskAssessment。真实数据可能为空；不能使用本地样例的 one/first/second 标识访问原后端。真实ZIP生成与其他写操作仍需相应测试对象和动作授权。
