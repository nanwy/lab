## 共同范围与验收

- 仅还原原 bundle 中从实验 simulate 可达的页面、操作、状态、请求和内容。完整依据为[主分析](../../docs/planning/s13-analysis.md)及[配置补证](../../docs/planning/s13-configuration-evidence.md)，按[有界查询](../../docs/evidence-query.md)核对；不增加业务规则、按钮、角色权限、图表视图或后端接口。
- 漏洞和确定缺陷按最小改动修复并记录触发条件、原行为与新行为；包括错误返回仍报成功、未定义变量、数据串用、资源泄漏和破坏图引用。未证实的风险不扩成通用加固项目。
- 沿用现有请求、Query、Form、Table和图组件；重复需求实际出现时复用，不为后续票预建框架、会话引擎或独立基础设施。不另做样式翻新、新交互或自动恢复策略。
- 实验、测试任务、蓝军、剧本、智能蓝军、兵力和轮次标识按原来源分别使用。请求失败不伪报成功，切对象和离页清理本页请求/定时器/连接，错误只提示一次；不添加无证据的字段必填校验。
- 验证原关键流程及本次修复的缺陷；已通过且未受影响的结果直接复用。不要求每个子流程重复一套失败/并发/权限组合测试，不新建测试平台，不默认全量check或构建。类型、lint、格式仍按仓库规则定向执行。
- 两种导入参数差异、未拼query、历史日志范围等未知协议保留原请求并注明未知，不猜参数。type7缺失链明确不可用；type8仅已有节点配置；终端编辑及iho策略不可达。S14独立大屏和module2–6其他入口不扩入本组。
- 静态复刻与真实联调分开记录，真实资源、上传、检查或工具执行须有明确测试授权；真实服务是否可用不成为新增产品能力或额外验收项目。各票记录实际交付及剩余缺口，整片按实施计划收口。
