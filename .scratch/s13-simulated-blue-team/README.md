- 每票是可演示的业务闭环，同时交付必要适配、UI和测试，不单拆API基础、通用框架或最后统一测试票。类型检查按最小受影响项目，lint/格式显式选改动文件，UI浏览器测试限定本票和直接消费者，不默认全量check/构建。

- 原status=2仍return true、自引用、未定义分页变量及timer/WS泄漏属于确定前端缺陷，修正并记录；两导入参数差异、未拼query及历史日志范围属于协议疑点，保留静态事实，不偷偷补参数或猜业务规则。
