# S13-03：智能蓝军四页签配置

**Type:** AFK

**User stories:** US035；F041 模拟蓝军；R089 内部流程

## What to build

在同一智能蓝军详情内完成概览、能力导入/技战术阅读、决策引擎和兵力角色的节点/能力配置，统一统计刷新与状态清理。

## Acceptance criteria

### 智能蓝军概览能力导入与技战术阅读

- [ ] 还原原四页签及详情/统计：名称、能力场景、描述、技战术数、攻击倾向、兵力数、启用引擎数和能力维度图；不新增指标、视图或图表交互。
- [ ] 能力维度默认首项，支持维度切换、搜索、10/20/50分页与逐项/当前页全选；选择按维度保存，关闭清选择，不将全选扩为全部服务端结果。
- [ ] 导入提交dimensions/dimension_id/ability_ids，至少一项；成功后刷新能力和统计；清空确认后POST clear并刷新，失败保留数据。
- [ ] 技战术展示树、子技术数量、is_exists和指令数；点击能力读取subtolgy详情，递归展示field_type1–4输入/输出样例，不增加技战术编辑。

### 智能蓝军决策引擎保存

- [ ] 读取并按engine_type排序原四类引擎，编辑is_enabled/weight；仅校验启用项权重0–1，不增加总和等于1规则；按原configs请求保存，成功重读引擎和统计，失败保留编辑。

### 兵力角色节点与能力配置

- [ ] GET force_allocation消费data.items，默认首角色；新增POST name、修改PUT name，trim非空最多20字；删除确认后刷新角色与统计并清被删选择。
- [ ] 切角色回节点配置；适配终端读取及共性提取使用当前智能ID/角色ID；工具字段为tool_name/version_name；删除末页退页行为按原保留。
- [ ] 原智能terminal包装器不拼调用方filter，保留请求差异，不声称后端已接受分页；编辑挂载但不可达，不新增PUT编辑按钮。
- [ ] 能力配置GET data.dimensions，count=0禁选；POST dimension_ids为所有勾选维度，成功重读；没有角色时不发角色域请求。

## 验证

沿现有浏览器/HTTP边界检查能力导入、引擎保存、角色与能力配置闭环，以及实际改动的失败恢复和切换清理。技战术与图表核对原展示；不为每个页签另建全套异常测试。参数和细节以证据文档为准。
