## 已确认的共同边界

- 只还原原 bundle 已有页面、内容、请求及交互，保留原静态图表、零计数与空白区域，不补成完整实时产品。事实与定位见[证据分析](analysis.md)。
- 不新增业务刷新按钮、轮询、WebSocket、重连、业务钻取、角色规则或实验菜单入口。原每秒显示时钟、日志滚动和图形动画按原行为保留。
- 任务级风险、日志和网络请求与 S13 蓝军实例级接口分开；各路由参数按原消费位置使用，禁止猜字段、混用 ID 或推导新业务数据。
- 只修影响当前页面正常使用的确定缺陷：缺失回调抛错、空数据残留、上下文串数据、图形与动画资源未释放。沿用统一请求、错误处理和会话规则，不扩成通用加固项目。
- 复用已有组件；出现第二个实际消费者时再提取必要的共用部分。不预建大屏框架、实时引擎、通用图表平台或无使用者的适配层，不做样式翻新。
- 每票交付完整可见页面、实际请求接线及定向验证。检查原关键流程与本次修复，不重复失败/权限/并发全组合，不默认全量 check、构建或全站浏览器回归。
- 静态隔离验收与真实联调分开记录；不请求未知副作用接口，不将自造样例通过写成真实服务兼容。真实字段空值、权限、数据和媒体可用性仍需实测。
