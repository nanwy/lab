# S15 公开课程本地实施票

日期：2026-10-27。用户已确认合并为 4 票并落本地文件。范围为 F005、F006、F007、R006/R007；拆票不代表业务已实现，当前进度只维护在[实施计划](../../docs/planning/page-rebuild-implementation.md)。

## 共同边界

- 只还原原 bundle 可达功能和正常行为，修复有证据的实际缺陷；不做样式翻新、新功能或通用框架建设。
- 以[S15 分析](../../docs/planning/s15-analysis.md)的最小实现边界为准。原件查询和静态证据见[视频](../s15-evidence/video.md)、[实操](../s15-evidence/practice.md)、[配套功能](../s15-evidence/support.md)。调查记录不是新增功能清单。
- 视频采用 hls.js 与原生控件，日志签名采用 js-md5；原有拖拽需要时采用 react-draggable。随业务接入、核对兼容版本并锁定，不另拆依赖建设票。其它功能复用现有 TanStack、Zod、shadcn、NiceModal、Quill、Viewer.js、DOMPurify、xterm 和 Guacamole。
- 不增加自动续播、暂停/离页补报、离线缓存、跨标签页同步、通用播放器、额外表单规则、操作项目选择器或原来不可达的截图笔记/模板导入。
- 原成功后的本地更新或重读分别保留，不统一追加请求。已处理请求错误不重复提示；切课、切节和卸载清理本票请求、媒体、监听和定时器。
- 正常、加载、空和错误按对应行为验收；只验证本票及直接影响的消费者，不另拆测试/审计票，不默认全量 check、构建或全站回归。
- 静态实现、隔离验收和真实联调分别记录。真实操作授权沿用项目限制，出票不授权学习日志、评论、笔记、答题、环境或产物生成等真实写入。
- 每票记录实际交付和残余缺口；缺失协议不靠猜字段、猜端点或模拟成功补齐。四票的功能覆盖与已完成结论分开，不能以票已创建宣称 S15 完成。
