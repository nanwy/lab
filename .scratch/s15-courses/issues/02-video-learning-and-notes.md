# 02: 视频学习与课程笔记

**What to build:** 学员可以在所选课程章节播放视频，按原时机记录学习日志，并使用课程我的笔记、共享笔记、评分和视频驻点。沿用原播放控件及笔记交互，修复日志串用、媒体清理和嵌套目录驻点定位。

**Blocked by:** 01: 课程浏览与配套内容的已交付课程路由、目录及当前章节基础；不依赖其尚缺契约的批量导出子项。依赖课程详情、真实目录、当前章节和章节定位接点；不依赖 03 或 04。

**Status:** completed

- [x] HLS 使用 hls.js 配合原生视频控件，保留原有播放、暂停、拖动、源切换和已证实的恢复行为；直接媒体继续使用原生视频，不自建播放器控件或流媒体引擎。
- [x] 原增加播放次数的动作、已完成章节分支、每 40 秒日志及结束上报按原链衔接；日志仍按已加载分片记录，不把它改成观看时长或新增反作弊规则；不重复发送 01 已接入的章节动作。
- [x] 日志保持原分片内容、总时长、毫秒时间和签名拼接，用 js-md5 计算摘要。用当前页面/章节内最小缓存避免串课，成功只清已提交部分，失败不伪报成功；不增加持久化、后台补报或暂停/离页上报。
- [x] 切课、切节、卸载时清理媒体实例、监听、定时器及旧回调；迟到成功不删除新章节或新累计的日志，旧响应不覆盖当前上下文。
- [x] 课程笔记使用课程专属列表与元数据协议，复用现有富文本、图片、笔记详情、保存、分享、删除和 Word 导出能力；支持原搜索、新建/改名、正文编辑和分享，不混用个人归档列表地址。
- [x] 共享笔记列表、详情、推荐度、本人评分及原评分操作可用；笔记弹窗保留原页签、拖动和局部全屏行为，复用现有组件及成熟拖拽库。
- [x] 视频章节按原条件创建和使用笔记驻点；从个人笔记跨页进入时按原准入与章节、播放位置定位，修复章下小节找不到的问题。保留原 0 秒驻点限制，不新增最后播放位置自动续播、截图笔记或模板导入。
- [x] 定向验证媒体切换/卸载、原上报时机与签名、在途请求期间新分片保留、笔记保存重开和跨页驻点；复查直接影响的既有笔记消费者，记录媒体与真实日志等未实测项。

**已知限制：** U03 的原生 HLS 分支没有等价分片日志链；保留该分支与限制，不另建跨浏览器日志方案。服务器去重和学习进度算法未实测，不能以隔离样例通过宣称真实进度兼容。
