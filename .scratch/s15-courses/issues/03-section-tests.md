# 03: 章节测试

**What to build:** 学员可以从课程章节打开本节测试，逐题选择并保存答案、提交整节测试、查看原结果和解析，并重新测试。保持原题型、完成态及重置规则。

**Blocked by:** 01: 课程浏览与配套内容的已交付课程路由、目录及当前章节基础；不依赖其尚缺契约的批量导出子项。依赖当前课程、章节和章节工具入口；不依赖视频播放器、课程笔记或实验环境。

**Status:** ready-for-agent

- [ ] 在原章节条件下显示并打开本节测试，按课程和章节读取整节题目；支持原单选、多选、判断，保留题目、分值、选项及既有答案。无题时显示原空态。
- [ ] 每次选择调用原逐题保存请求，成功才更新本地答案；课程、章节和题目 ID 各自对应，不使用实验检查点的请求替代。
- [ ] 未完成时可提交整节；按原成功判据刷新题目，完成后禁选并展示正确/错误/未答、答案与解析；不增加必须全部作答或客户端评分规则。
- [ ] 已完成时可重新测试，沿原重置请求与成功后刷新恢复作答；不新增确认框、重试次数限制或本地持久化答案。
- [ ] 保留原测试弹窗的打开、关闭及拖拽行为，使用既有弹窗与成熟库；切章/关闭后旧响应不覆盖新测试，提交失败不显示成功，错误提示沿用统一请求层。
- [ ] 定向验证逐题保存成功与失败、三种题型、整节提交后的结果、重新测试、空题及章节切换；仅运行本票及直接影响的检查，记录真实计分、次数和权限未实测。
