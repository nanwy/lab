# 04: 课程实验与环境

**What to build:** 学员可以从视频章节的本节实验或实验章节正文进入原课程实验，阅读手册、完成检查点题目和 Flag，并启动、查看、延长和释放对应环境，打开已有控制台。修复原手册错接线和异步资源清理缺陷。

**Blocked by:** 01: 课程浏览与配套内容的已交付课程路由、目录及当前章节基础；不依赖其尚缺契约的批量导出子项。依赖当前课程、章节和章节工具入口；所需 S07 控制台已交付，不依赖 02、03 或后续 S18。

**Status:** ready-for-agent

- [ ] 视频章节的本节实验弹窗与实验章节正文复用同一份实际实验行为，按原列表首项进入操作项目；不新增原来没有的项目选择器，不提前建设其它实操入口的通用框架。
- [ ] 按原测试类型及检查点分支展示实验内容、附件、手册和解答；保留手册开放条件与倒计时，修复关卡手册可见状态错域及关闭调用缺失，不新增购买或解锁接口。
- [ ] 检查点取题、选择保存、完成、重置及 Flag 提交走课程检查点协议，保持课程、章节、操作项目和检查点的归属；保留关卡顺序门控、完成后禁用和原重新测试条件，不套用整节测试请求或新增校验。
- [ ] 成功后的局部完成展示和原重读行为一致；单检查点成功不被解释为服务端整课完成，不另造总进度或计分规则。
- [ ] 接通原课程环境列表、状态、启动、释放、延时和节点刷新。使用课程资源类型与操作项目 ID，保持环境模板、运行 ID 和检查点参数各自语义；不套用 S07 固定实验类型的拓扑运行接口。
- [ ] 保留原启动/释放中轮询、运行资源、倒计时自动释放与手动释放条件；查询和启动的共享字段来源分别按证据处理，不自行合并或增加延时时长表单。卸载清理不额外释放远端环境。
- [ ] 按原节点类型展示地址、账号和控制台，复用既有文本/图形控制台及原外部协议入口；不新增操作机业务、终端协议或图形连接器。
- [ ] 切章节、操作项目、检查点或关闭页面时清理监听、轮询和延迟回调，旧状态响应不影响新环境；保留原失败语义，不新增自动重试策略。
- [ ] 定向验证两个实验入口、题目/Flag、关卡门控、手册修复、环境状态迁移与释放/延时、控制台参数和切换清理；使用隔离边界，记录真实环境、共享语义和控制台连通未实测。

**已知缺链：** U02 的对抗检查与防御上传在原课程调用方缺少回调及上传地址。保留明确不可用原因，不能调用其它业务的候选端点补猜，不能显示虚假检查或上传成功；补齐该动作需要独立课程协议证据。
