## 初始化缺口补齐与 AGENTS 对齐

- Button/Input/Table 从 shadcn 官方 `new-york-v4` registry 引入，补齐官方 neutral light/dark token 和 Tailwind v4 主题映射。原生元素样式与 shadcn `data-slot` 隔离；桌面及 390px 视口已检查实际表格/表单页面。
- `config.ts` 统一校验公开环境变量，提供 `.env.example`。bootstrap、诊断页与 loader 使用同一个模拟模式判定；生产及关闭 MSW 后不发诊断请求，自定义 API 前缀也由 MSW 拦截。
- 路由 loader 与页面共享 queryOptions、QueryClient 和缓存，浏览器确认加载与重进页面不会重复查询有效缓存。
- 流读取阶段的取消、超时、断流及 text/blob 读取失败归一化为 ApiError，取消传递到底层。错误默认不携带原始消息、字段或 cause；业务域只展示明确批准的消息和字段。
- 业务错误协议由域适配函数明确指定，移除 success/ok 多 key 猜测；诊断、样本分页和更新响应均经过 Zod 契约校验。
- 拓扑输入拒绝重复 ID、缺失坐标及名称等不合法样本，保留未知图元及折点元数据，继续明确报告无效父组、端口和端点。
- AGENTS.md 中临时的“当前未完成”描述已调整为长期约束；具体实施状态由本文维护。未修改用户已有的页面功能映射文档。

验证：Node 24 下 frozen-lockfile 安装、类型、lint、格式、9 个 Vitest 文件的 41 项测试、生产构建、7 项开发模式 Chromium 测试及 3 项生产/模拟关闭/自定义 API 模式测试通过。`pnpm check` 包含上述所有检查。

## 共享 shadcn 全量安装补验

按用户指定改为 `packages/ui` 单一组件来源。使用官方 `shadcn@4.22.1 add --all --yes --overwrite --cwd packages/ui` 成功生成 CLI 当前全量选择的 61 个组件文件及 `use-mobile` hook；主题位于该包 `src/styles/globals.css`。应用 Button/Input/Table 已切换为 `@workspace/ui/components/*`，删除应用内副本。不是把 registry 索引中的所有历史条目都宣称为已安装。

安装曾异常停留在 CLI 子进程的 pnpm 依赖阶段，未生成组件；明确 Node 24 路径、统一 workspace store 后重跑成功。尚不能据此认定此前阻塞的唯一根因。重跑后补做根目录安装，恢复应用到共享包的 workspace 链接，并将 resizable 依赖固定为 4.14.6。

官方源码的项目适配：ComboboxChipsInput 的 props 显式排除 input 不使用的 children，消除未使用变量 lint 错误；其余源码仅格式化。共享包及应用类型检查、lint、格式、41 项单测、生产构建、7 项开发浏览器测试、3 项运行模式测试和离线 frozen-lockfile 安装通过。尚未逐一对全部复杂组件组合做浏览器交互验收；构建仍有主包超过 500 kB 的提示。
