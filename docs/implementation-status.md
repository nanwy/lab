## 初始化缺口补齐与 AGENTS 对齐

- Button/Input/Table 从 shadcn 官方 `new-york-v4` registry 引入，补齐官方 neutral light/dark token 和 Tailwind v4 主题映射。原生元素样式与 shadcn `data-slot` 隔离；桌面及 390px 视口已检查实际表格/表单页面。

- 路由 loader 与页面共享 queryOptions、QueryClient 和缓存，浏览器确认加载与重进页面不会重复查询有效缓存。
- 流读取阶段的取消、超时、断流及 text/blob 读取失败归一化为 ApiError，取消传递到底层。错误默认不携带原始消息、字段或 cause；业务域只展示明确批准的消息和字段。
- 业务错误协议由域适配函数明确指定，移除 success/ok 多 key 猜测；诊断、样本分页和更新响应均经过 Zod 契约校验。
- 拓扑输入拒绝重复 ID、缺失坐标及名称等不合法样本，保留未知图元及折点元数据，继续明确报告无效父组、端口和端点。
