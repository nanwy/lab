# 账号能力与操作范围矩阵

这是一份权限调查与验收计划，不是已确认的后台角色表。目前没有后端角色枚举或不同账号运行证据，不能发明“高级学员/班长”等角色，也不能从URL中admin推导管理员身份。

## 身份与能力分开

当前可从代码识别的条件包括Token会话、用户信息、can_enter、shared、readOnly、lock、topo_edit、task_type，以及课程/任务/实验/节点标识。

| 能力画像（非真实角色名） | 代码/业务依据 | 验证操作范围 | 未确认项 |
|---|---|---|---|
| 未登录/会话失效 | 请求拦截、403“未登录”分支 | 登录入口，受限页面拒绝，退出后清理 | 初始HTTP认证及验证码 |
| 未激活 | 403“未激活”及activate路由 | 显示激活状态/引导；是否可激活待确认 | 激活实际操作主体 |
| 已登录学员 | 当前用户与学员路由 | 本账号可见的课程、任务、资源和个人数据 | 实际角色名称、菜单与功能配置 |
| 已分配课程/训练/考核的参与者 | URL对象层级及任务组件 | 查看、学习、作答、提交与结果 | 分配/时段/次数/成绩发布规则 |
| 个人实验的可编辑使用者 | 实验写接口及编辑事件 | 新建/编辑、拓扑保存、笔记；运行权限单独核对 | 所有权、配额、资源约束 |
| 共享/只读访问者 | shared/readOnly分支 | 只读呈现；哪些运行操作仍允许待核对 | 共享机制和授权来源 |
| 锁定或运行中的实验使用者 | lock、节点/环境状态 | 条件禁用修改/删除、允许的生命周期动作 | 锁定与运行是否等价；服务端最终约束 |
| 有装备使用/预约资格的学员 | equip_practice与equip_booking | 允许的训练、时段查看、预约/取消 | 审批、冲突、禁用日管理权限 |
| 任务成员/席位持有者 | 演练、保障任务的成员/席位相关代码 | 该成员允许的操作、消息、评价及成果 | 是否存在额外视角角色及权限 |
| 资源消费者/文件所有者 | 公开/个人资料、共享笔记 | 浏览、下载、自有对象编辑和分享候选 | 目录写权限、配额、分享范围 |

教师/管理员仅作为发布课程、分配任务、配置资源、评价和成绩公布等上游关联。需要保留它们给学员带来的状态变化，不建设教师后台或管理员后台。

## 按对象验证而非仅按页面验证

| 对象域 | 需要比较的范围 | 允许操作候选 | 主要验证条件 |
|---|---|---|---|
| 用户与个人设置 | 当前用户/他人 | 查看、自身编辑、改密码 | 可编辑字段、会话失效、禁止伪造用户归属 |
| 课程/章节 | 公开/已分配/未分配/下线 | 查看、学习、练习、日志、资源下载 | can_enter、课程状态及任务归属 |
| 训练/路线任务 | 分配给本人/其他成员/无分配 | 领取、开启、作答、作业、完成 | 阶段、次数、时段、任务与科目对应 |
| 考试 | 未开始/进行中/已提交/结束 | 进入、保存答案、交卷、查看成绩 | 时段、次数、结果发布；不能修改他人成绩 |
| 实验/拓扑/节点 | 自有/共享/只读/锁定/运行中 | 设计编辑、保存、运行、控制台 | 各动作独立校验，节点必须属于当前实验 |
| 装备/预约 | 可见/可用/已占用/本人预约 | 训练、预约、取消 | 时段、冲突、容量和所有权 |
| 文件/笔记 | 本人/公开/共享/课程附件 | 读、上传、改、删、分享、导出 | 路径范围、对象归属、配额、分享/评分权 |
| 演练成果与评价 | 本人/团队/其他席位 | 查看、提交、修改、评价 | 当前席位、任务阶段、可操作对象 |
| AI会话/控制台 | 本人会话/指定节点/过期会话 | 建立、发送、关闭、重连 | 授权、归属、票据/连接有效期 |
| 统计/排行/态势 | 个人/团队/任务/场景视角 | 读取、筛选、钻取 | 数据范围与公布状态；不能默认全部开放 |

所有候选动作初始验证状态为“未知”。UI隐藏/禁用与后端拒绝要分别记录，前端检查不能替代后端授权。未经确认不对他人ID做探测，不把越权尝试当正常联调。

## 权限证据记录格式

逐个测试记录：功能F编号、账号匿名标识、后端返回的真实角色/能力字段（脱敏）、对象域和归属、前置状态、UI可见性/可点击性、操作语义、请求/响应摘要、业务状态、R/A/C/V证据、结论及残余未知。

建议测试画像：无会话、可用测试学员、可编辑实验、共享只读、锁定/运行状态、已分配任务/考试、装备预约、不同成员席位。画像可以由同一个测试账号的不同资源状态构造，不预设必须创建相同数量的账号。

## 联调副作用分类

| 类别 | 示例 | 当前策略 |
|---|---|---|
| 已确认无副作用读取 | 用户信息、列表、详情、状态查询 | 通过允许访问的环境按白名单验证；尚未实际调用 |
| 普通数据变更 | 新建/改/删实验、笔记、资料、分享、已读、领取 | 本地模拟；明确测试对象后逐项接通 |
| 学习/考核结果变更 | 播放日志、作答、Flag、交卷、作业、评价 | 本地模拟；使用隔离测试任务验收 |
| 环境资源变更 | 启动、停止、释放、延期、节点/链路配置、工具执行 | 本地模拟；确认测试节点、资源范围后验收 |
| 会话与授权变更 | 登录、退出、改密码、建立控制台连接 | 分开规划与授权，真实凭据不入库/日志；改密码由用户完成 |
| 产物生成/下载 | Word、PCAP、资料打包、离线包 | 核对是否生成后端任务及含敏感数据，再开放 |
| 未知语义 | 动态URL、未核对请求、GET删除 | 默认不请求，不以HTTP方法判定只读 |

这里限制的是当前联调阶段，不删减最终功能目标。真实写操作开放后仍以原后端能力和测试范围为边界。
