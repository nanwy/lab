## 契约

路径均由统一客户端加 API 前缀。响应在适配边界以 Zod 校验，不猜测备用 key。

| 操作          | 请求                                                               | 成功判据                                                                                  |
| ------------- | ------------------------------------------------------------------ | ----------------------------------------------------------------------------------------- |
| 今日/历史列表 | GET `/front/simulation/experiment/` 或 `more/`；`page/size/search` | `count/results`，列表消费 `id/name/desc/node_count/start_status/create_time/source`       |
| 新建          | POST 同上；`name/desc`                                             | 返回 `id`                                                                                 |
| 详情          | GET `:id/?more=1`                                                  | `id/name/desc/node_count/user_name/tags/overview/release_type/max_duration/tags_category` |
| 编辑          | PATCH `:id/?more=1`                                                | 返回 `id`；列表仅提交名称/概述，详情另提交 `tag/release_type/max_duration/category`       |
| 删除          | POST `delete/`；`ids: [id]`                                        | `status=1`                                                                                |
| 场景列表      | GET `expreiment_scene/`（保留原拼写）；`page/size/search`          | `count/results`，场景消费 `id/name/sub_user/create_time`                                  |
| 导入          | GET `select/:sceneId/`（有写副作用）                               | `status=1`                                                                                |
| 标签          | GET `/front/base/tag/?otype_plus=tag&nopage=1`                     | 数组中的 `name`                                                                           |

表单遵循应用 AGENTS 的 TanStack Form + Zod + Field 示例；新建/列表编辑使用 NiceModal 函数式打开。列表与场景选择复用现有 TanStack Table 和分页组件。没有新增依赖、通用管理器或客户端业务 store。

## 上下文、权限与差异

- Query 以实验 ID 区分缓存，Context 只投影当前详情；切换 ID 重挂载实验容器并取消旧请求，离页取消命令，迟到结果不更新界面。根详情入口进入概述；未知子页显示 404。
- 新建、编辑、删除、导入成功后刷新受影响的列表或详情；失败保留输入、选择和记录。403 沿用账号失效/未激活/无权限分支，不冒充保存成功。
- 原个人实验页面的 `pjs/Djs/Ujs` 未按所有者、共享或锁定字段隐藏元数据编辑按钮。这里不凭其他实验运行器的字段臆造本页权限规则；最终授权由服务端决定，拒绝访问有独立验证。真实角色、配额及发布/删除影响范围仍未知。
- 原 `xjs/mjs` 实际没有渲染分类或标签筛选，`Djs` 没有渲染释放配置控件。保留已有数据但不新增这些控件；规划中的概括性描述以本次调用链证据为准。
- 说明使用无脚本 sandbox iframe 和 CSP 展示 HTML，不把服务端 HTML 插入主文档。富文本编辑、上传和 Word 等能力不提前在 S05 做近似实现，归 S10。
- 实验历史页签持久化、拓扑、运行环境、流量、笔记、检测与攻击页面不是 S05 的完成声明。子页保留实验 ID 和明确的后续切片提示；没有拿占位页冒充这些功能已完成。
- MSW 使用确定样本与标签页内持久化模拟服务，支持新建、编辑、删除和场景导入；与关闭模拟的接口拦截验证分开。未执行真实后端写入。
