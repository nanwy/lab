## 票01：实验场景与节点生命周期（2026-10-21）

复用 S06 正式实验拓扑页、节点菜单、统一 API 客户端、Query 和离页保护；没有重建画布、预建通用运行框架、添加延期或自动重试。业务实现约350行，未增加依赖。

### 行为与契约

- 实验继续使用唯一的 topo_id 和 task_type=6。状态 GET `/front/topo/{id}/status/?task_type=6`，nodes 按画布 UUID、edges 按业务行 data_id 显示；0–6 分别为未启动、启动中、启动成功、启动失败、关机、上传镜像中、暂停。
- 单节点启动/释放/重启/关机均 POST `/front/topo/{id}/node/{uuid}/{action}/?task_type=6`，body 为 `{}`。批量启动为 POST `/front/topo/{id}/node/start/?task_type=6`，释放为同 URL 的 DELETE，body 为 node_list UUID 数组。整图启动/释放 POST `/front/topo/{id}/{start|stop}/?task_type=6`，不添加请求体；所有变更以 status=1 判成功，失败复用统一 API 提示。
- 菜单按原节点状态和设备类型开放，保留锁图可运行、共享隐藏整图工具栏但允许适用节点动作、readOnly 禁止操作的差别，不从实验详情猜测权限字段。批量过滤分组和标注。保留“节点释放后会删除相关数据”的提示。
- Query 是运行事实的唯一来源，状态与链路着色只用于显示，不进入 X6 设计草稿、保存基线或连线配置。操作后重读状态；不引入自动轮询、后台作业跟踪或恢复机制。手动刷新和重新进入恢复服务端状态。
- 开启/关闭错误信息面板，列出 status=3 的节点/链路及错误，按更新时间倒序。运行过程中显示对应动作提示；运行、保存和冲突操作互斥，同步 ref 防止重复提交。
- Query 的 AbortSignal 取消旧状态请求；运行写入使用组件生命周期的 AbortController。沿既有离页提示允许用户离开，取消前端等待、忽略迟到结果，不因此发送远端释放请求。取消等待不代表撤销已发送的远端操作。

状态刷新保留设计草稿是本轮明确要求；没有沿原启动/释放后的整图重读覆盖当前编辑。原失败分支在本地直接设 status=3，本实现保留已读取状态并显示服务错误，避免用失败响应捏造新的服务端状态。

节点快照/镜像/NAT等运行资源、VNC/RDP/字符终端和操作机留在后续三票；场景 model=topo 不新增延期，未来学习/考核环境消费者仍归对应切片。

## 票02：节点快照、镜像与运行资源管理（2026-10-22）

复用 S06 画布、节点菜单、draw、统一 API、Query、现有表单/表格与确认提示；只补原 bundle 可达的节点资源动作。没有增加依赖、通用运行框架、后台自动重试或恢复机制，未实施票03/04控制台或S08流量操作。

### 行为与契约

- 快照：列表支持服务端搜索、每页10条、创建时间排序；创建名称最多32字符，状态0/1/3禁止创建。启用的快照禁止恢复；恢复提示覆盖当前环境，恢复/删除需确认，删除末页回到有效页。列表/创建使用 `/front/topo/{id}/node/{uuid}/snapshot/?task_type=6`；恢复和删除均使用 `/snapshot/{snapshotId}/resume/?task_type=6`，分别POST/DELETE空对象，不能按REST习惯改写原路径。
- 保存镜像：仅原设备类型可见，状态4且有关联镜像才进入。读取 `/front/node/image/list/{imageId}/`，编辑名称、文件名、CPU/内存/磁盘、类型/属性/系统、开放服务、系统/应用账号、IP方式/静态配置、描述与启动配置。沿原文件名去末扩展名、去中文及数组过滤规则，仅名称必填；保留未知镜像及config字段。保存使用原特殊路径 `/front/{topoId}/node/{uuid}/save_image/?task_type=6`，无 `/topo/` 段；失败保留输入，成功刷新状态。原读取密码key为 `password`，写入key为 `passwrod`，明确分开，不用猜key兼容。
- 详情：沿节点schema只读展示，补镜像服务/账号、静态IP、描述与启动配置；无schema明确提示。切换/关闭取消读取，避免迟到结果覆盖新目标。
- 转换：状态0且非共享可用，候选请求 `/front/node/convert/?nopage=1&device_type_id=…&icon_classify_id=…`；选中后只沿原链更新模板字段并保存draw，不新增节点PATCH。画布UUID、已有业务行ID、未知图字段及锁定状态保留。
- 入口：按原网络设备能力开放，先调用有副作用的 GET `/front/topo/{id}/network/{uuid}/`，再将所有业务节点的network_cut写入draw，重开仍显示入口。该GET不进入自动查询/重试；原动作在锁图时仍可用，共享时关闭。第二步失败保留原界面并报告错误，重试沿原入口调用，不另建部分成功恢复系统。
- NAT：运行成功的router/nat_net可用；列表搜索/分页、新增及确认删除。nat_type按snat/dnat/dnat_and_snat及原外部/内部IP必填规则，不额外增加格式限制。使用节点 `/nat/` 与 `/nat/{natId}/?task_type=6`，保持UUID和NAT记录ID各自语义。
- 上传：仅运行成功的libvirt且console_type=vnc开放，POST `/front/topo/node_run/{uuid}/upload_file/`，FormData只含file；保留Linux挂载/dev/cdrom与Windows光盘提示。
