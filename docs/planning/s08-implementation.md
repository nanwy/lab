## 原始证据与契约

通过有界查询读取原 bundle，以下偏移均为 Unicode 字符位置。

- `Ojs` @ 12682300：实验传入 `model=topo`、实验详情中的 `topo_id`、`task_type="6"`。链路操作使用图中边的 `data_id`，不能使用画布边 UUID。
- 链路菜单 @ 7564900–7565900：任一端类型属于 `libvirt/docker/vpcs/libvirt_middle_intercept/docker_webide` 时开放标记与嗅探。`readOnly` 阻止菜单；共享、锁图不是关闭所有运行操作的条件。
- `gPa` @ 6928600 附近、store @ 6848101：捕获配置为 `pcap_size` 和 `pcap_filter`（`proto/host/port`）；原包大小默认5、过滤器默认空，包大小必填且至少为1。捕获状态1/2/3分别为未启动、已启动、启动失败。
- `mPa` @ 6932300：链路记录支持分页、搜索、大小/创建时间排序、手动刷新、单项/批量删除、详情与下载；选择以文件名标识，未配置跨页保留。
- `Ijs/Rjs` @ 12683800–12691800：实验流量页两张表分别分页，默认每页5项；标记确认启停，记录支持搜索、跨页选择、详情、下载、删除和清空。重新查询后清空选择；没有该页自动轮询证据。
- 请求包装 @ 6078500–6081650：标记配置、启停与链路记录分别为 `/api/front/topo/{id}/edge/{edgeId}/capture_pcap_status/`、`start_capture_pcap/`、`stop_capture_pcap/`、`capture_pcap_list/`；实验标记列表为 `capture_situation/`，全图记录为 `capture_pcap_list/`，清空为 `all_pcap_delete/` 的 DELETE，选中文件删除为 `capture_pcap_delete/` 的 POST（`file_list`）。下载默认沿原 `/api/front/topo/capture_pcap_download/{name}`，地址通过同一 API 基址配置构造。
- `dPa` @ 6923400–6925700、store @ 6848101：嗅探使用 `capture_status/` 查询，`start_capture/`、`stop_capture/` 为无请求体 POST；成功后重读。状态1显示未启动，其他原状态显示已启动及后端 `cmd`，提供复制及 Wireshark 配置说明、操作指南。
- `lPa` @ 6923050 附近、`xG` @ 1805292：指南打开 `/media/handbook/Wireshark_install.docx`，使用品牌配置的 `onlyoffice_url` 拼接 `/web-apps/?filePath={当前origin+文件路径}&mode=view` 后新窗打开。本轮仅复用品牌查询并补消费该字段，不实现独立 Office 预览器。
- `M4a` @ 8007480 附近：实验 `task_type="6"` 隐藏流量模拟页签，不能仅因通用组件有 PCAP/脚本回放就增加实验入口。

## 实施边界

复用现有画布、菜单、统一 API、Query、表单、表格及错误提示，只增加本轮入口的必要业务接线。没有新增依赖、通用流量框架、轮询、自动重试、自动重连或持久化恢复。必要的对象隔离、读取取消与本地资源清理沿现有模式处理，离页不自动停止远端捕获或嗅探。

静态调用链与隔离测试分别记录；不把列表显示、命令复制或本地下载响应称为真实采集成功。未经明确测试对象和动作授权，不调用原后端执行捕获、嗅探、删除或清空。
