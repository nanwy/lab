## S10-R2：区分笔记写成功与刷新失败

- 范围：D1；个人和场景笔记 HTTP 适配及编辑流程。
- 写成功分别以 PATCH id、POST status=1 为准，去除 HTML 字符串相等要求；刷新接受服务器规范化正文。
- 写失败继续保留未保存稿；写成功但刷新失败明确显示“已保存，内容刷新失败”，允许单独重读，不再次写入。
- 提交后继续输入的内容不得被规范化结果、重读或旧查询覆盖；保持正确 dirty 基线和离页保护。场景刷新成功获得 noteId 前禁止导出，避免导出旧 ID。
