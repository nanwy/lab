日期：2026-10-27。本记录保存 S15-01、S15-02 的实际实现和验证；当前切片状态唯一来源为[实施计划](page-rebuild-implementation.md)。原始范围见[补证分析](s15-analysis.md)，工单见[本地索引](../../.scratch/s15-courses/README.md)。未实施 03–04。

## 第一票交付范围

- 公开课列表：方向/分类/岗位/等级/类型/难度/完成状态、200ms 防抖搜索、分页和页容量，方向并入重复 tag 参数；等级和难度分别消费原字段。空态、加载、失败重试和关闭课程提示已接入。
- 详情和目录：公开课独立路由、课程信息与收藏、平铺进度与播放次数、章下小节完成态、默认/手动选节及按章节 ID 定位。详情深链直接读取，列表准入沿用 brief/is_open，笔记跨页准入仍使用 can_enter。
- 资料和章节内容：资料目录、面包屑、排序、选择、直接下载、MP4 弹窗；讲义 iframe/Office/直接地址、章节附件、工具和实验视频。原资料表没有 Office 点击接线，未新增该操作。PDF/TXT 局部全屏仅调整原弹窗显示，不新增文档渲染器。
- 评论和推荐：评论分页、创建、回复、仅本人一级评论删除及确认、删除末页最后一项后回有效页；收藏/取消、相关课程读取、空态及跳转。
- 首页、导航、收藏和笔记中的课程链接改为已落地的具体路由，保留原准入检查、章节和驻点状态；没有新增本票之外的业务入口。
- 全部请求使用统一客户端、课程域函数和既有 Query；表单使用既有 Form/Zod/Field，资料表使用 Table，弹层复用共享 UI。第一票没有需要独立拖动的原入口，因此未添加拖拽依赖，也未安装属于第二票的 HLS/签名库。

## 原缺陷与契约边界

1. 评论删除原回退条件依赖本页未传的 type，现按实际分页与删除结果回到有效页；没有增加回复删除或新的内容规则。
2. 目录按真实小节层级定位，章容器 ID 不冒充章节 ID；视频当前播放位置由 02 负责，本票不做自动续播或放开 0 秒驻点。
3. 课程/目录/弹窗切换按实例和 Query key 隔离，命令离页取消；旧响应不覆盖新课程。章节切换关闭已打开的旧章节媒体，弹窗关闭卸载对应视频或 iframe。
4. 资料允许原消费者可显示的缺失/空时间，不将排序字段误设为整份列表必填；重复行标识明确报错，避免多选合并不同文件。详情独立解析，不要求仅列表卡片使用的 type 字段。
5. **U01 未完成**：课程批量导出只有原多字段兜底，没有唯一响应契约。当前按钮禁用，以“批量导出暂不可用，请使用单文件下载。”说明；没有发起未知产物生成、猜下载字段或报告成功。单文件下载已单独验证，不能代替批量导出。01 因这个剩余子项保留 blocked，其课程路由/目录/章节基础可供 02–04 使用。

所有响应约束与样例均依据本版静态消费位置；没有本轮真实响应取样，不宣称线上字段类型、必填性、空值或权限已确认。

## 第二票：视频学习与课程笔记（2026-10-27）

### 实际交付

- 视频采用锁定的 hls.js 1.7.3 和原生 video controls；原附件/实验视频继续使用原生媒体。保留原加载、分片、网络/媒体恢复、缓冲恢复与异常暂停单次保护，主动 pointerdown/seeking 重置保护。切章/切课/卸载取消请求，销毁媒体实例并清理监听、周期和恢复计时器。
- 初次默认选择不增加播放次数；用户点击视频章节时调用原 catalog/{sid}/play/ 并刷新目录。播放器按课程、章节和地址身份存活，目录元数据刷新不重建媒体。未完成章节每 40 秒上报，完成章节跳过周期上报，结束事件仍上报并停止周期；暂停、切节、离页没有补报。
- FRAG_LOADED 按原 relurl → duration 记录已加载分片，总时长取整、毫秒时间和原拼接串 MD5（js-md5 0.9.2）保持原协议。缓存只在当前媒体实例内存中；提交捕获快照和每项版本，成功仅删除同版本的已提交项，失败保留。周期请求尚未返回时，结束事件仍可独立提交；没有新增防重锁、持久化或后台队列。
- 我的/共享笔记使用课程专属 user/note、share/note 列表，元数据显式发送 type=1、course_id、section_id；不套用个人归档列表。复用既有富文本及图片、详情、正文 PATCH、分享、删除和 Word 导出。课程保存不新增详情 GET，不引入归档脏稿确认流程。
- 共享详情、推荐度和本人 1–5 星评分复用既有组件。笔记弹窗保留页签、标题拖动、视口边界和局部全屏；拖动使用 react-draggable 4.7.2/nodeRef，未自建拖拽引擎。
- 视频章节新建/改名可记录驻点，暂停并读取 currentTime，继续拒绝 0 秒。课程内驻点直接定位；个人归档跨页沿既有 can_enter 准入，携带章节及时间，能够定位章下小节并在元数据就绪后设置位置。手动选节清除旧驻点意图，没有最后播放位置自动续播。
